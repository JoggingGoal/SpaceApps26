When GitHub Codespaces reconnects:
1. Open Terminal in /workspaces/SpaceApps26
2. Commit/back up any unique current files before overwriting.
3. Upload the ZIP into the root of SpaceApps26.
4. Run: unzip -o Green_Revolution_All_Pages_Final_Recovery.zip
5. Run: python3 app.py
6. Open port 8000 -> /HOME/home.html

If rebuilding a brand-new empty repository, extract these files into its
repository root (not into an extra nested folder).
